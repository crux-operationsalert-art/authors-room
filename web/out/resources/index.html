Step 1: create a Google sign-in client (once)

  1. In Google Cloud Console, pick (or create) a project for this app.
  2. APIs & Services → Library: enable Cloud Resource Manager API, Service Usage API, API Keys API and Cloud Billing API.
  3. APIs & Services → OAuth consent screen: External, add yourself as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application. Authorised redirect URI:
    https://hbmelugvtvinmqwkxtgx.supabase.co/functions/v1/google
  5. Paste the client ID and secret below. The secret is stored encrypted on the server and never shown again.
